# 客户手机端装 ChatGPT（iOS）

交付时客户会问「手机/平板上怎么用」。先把结论说清：**App Store 的地区跟账号走，不跟 IP 走**。人在国外但持国区账号，打开商店看到的仍是国区，照样搜不到 ChatGPT。

## 三条路，按省事程度排

| 路线 | 适用 | 代价 |
|---|---|---|
| **PWA：Safari 打开 chatgpt.com → 分享 → 添加到主屏幕** | 首选。手机上写文案、看复盘、审稿完全够 | 零成本、不用换区、不用多一个账号。先推这条，能挡掉后面所有折腾 |
| **注册所在地区 Apple ID** | 人在海外（美/日/欧等已上架地区） | 用真实地址，能绑当地卡付 Plus，比美区省事 |
| **注册美区 Apple ID** | 人在国内，或所在国没上架 | 要走下面的流程 |

## 国内注册美区 ID（+86 手机号即可）

不用美国手机号、不用美国信用卡。iOS 27 实测：

1. 退出原账号（先确认照片已同步 iCloud，保留本地数据）
2. **拔 SIM 卡**，只连普通 WiFi，**不开任何代理**
3. 设置 → 通用 → 语言与地区：语言 English，地区 United States
4. 设置首页顶部 Apple 账户 → `Don't have an Apple Account?` → 年龄选 `Adult`
5. 姓名生日随便填（生日须满 18）→ 邮箱点 `Don't have an email address?` 现场申请免费 iCloud 地址（**创建后不能改**）
6. 密码 ≥8 位，含大写 + 小写 + 数字
7. 手机号默认 `+1`，**改成 `+86`** 填国内号，选短信验证
8. `Agree` 后等自动登录，中途别退
9. 验证：Apple 账户 → Payment & Shipping，账单地址显示 **USA** 即成功；不添加任何付款方式

**常见报错**：「此时无法创建你的账户」→ 确认地区真改成美国了、关代理、换 WiFi、隔几小时再试；付款方式没有「无」→ 系统没当成新号，重来或改走 `account.apple.com` 网页注册。

## 请人代注册（朋友在美国）

**关键不是「他帮你注册」，是「注册完账号归谁」。**

- 让他**用电脑浏览器走 `account.apple.com`**，不要用他的 iPhone——手机上注册要先退出他自己的 Apple ID，会动到他的照片/iCloud/已装 App，他多半不愿意，这一步决定了这段请求能不能谈成。
- 国家/地区选 `United States`（选错后改要清零余额、取消订阅）。
- **手机号填 +86 你的号**，验证码发到你手机——这是控制权的锚点。
- 注册完必须做的五件事，顺序别乱：① 立刻改密码；② `登录与安全` 里**移除他的受信任设备**（代注册最致命的遗漏，留着等于他有第二把钥匙）；③ 设恢复密钥并抄下来；④ 确认没绑任何付款方式；⑤ 自己 iPhone 的 App Store 里单独登录（不登 iCloud）验证能搜到 ChatGPT。
- 别让他用他的 Apple ID 建号再「转给」你——苹果账号不能转让；别加进他的家庭共享。

## 付款：美区号绑不上国内卡

苹果按**发卡行 BIN + 账单地址国家**做支付隔离：美区 ID 只认美国发行的卡，国内双币卡（哪怕印着 Visa）会被拒，常见症状是「添加时显示成功、扣款时报付款方式无效」。**反复试会触发风控锁号**，别拿主号试。

可行顺序：

1. **礼品卡（最干净）**：让朋友在 apple.com 或美国超市买 Apple Gift Card 发你卡号 → App Store 兑换 → 用余额订阅。账号任何一环都不在他手里。
2. 美元虚拟卡：适合长期续费，成功率较高，需挑靠谱平台。
3. 代充平台：最省事，有封号风险。

网页订阅（chatgpt.com 直接刷卡）用国内双币卡成功率极低，多次失败会给账号打风险标记；只下免费 App（含 ChatGPT 本体）不需要任何付款方式。

## 对客户的交付口径

别教花店老板折腾 Apple ID。默认路线是 **Safari 添加到主屏幕**，30 秒完成、零售后；真到必须装 App 再远程帮她开非大陆区 ID。客户版使用手册里不要出现「美区」「礼品卡」这些词，只写「手机上用浏览器打开，可以加到桌面」。
