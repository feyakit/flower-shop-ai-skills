## 二、施工顺序（别跳步）

1. **装 ChatGPT 桌面版** → 登录 → 设置里给「完全访问」权限（否则不能读写文件、不能跑命令）
2. **装 Obsidian**（1.12.7 正式版）→ 建库文件夹 `花店经验库`
3. **装 Chrome** → 客户登录小红书网页版 **和** 创作服务平台，**确认是同一个账号**
4. **装 uv**，把 `xiaohongshu-skills` 放进 skills 目录，`uv sync`
   - 国内慢就设镜像：`UV_DEFAULT_INDEX=https://pypi.tuna.tsinghua.edu.cn/simple`
5. **Chrome 加载扩展**：`chrome://extensions` → 「开发者模式」→「加载已解压的扩展程序」→ 选 `xiaohongshu-skills/extension`
6. **验收闸门**：跑 `check-login`
   - 通过 = 返回客户昵称和小红书号；不通过 = 停下修桥接，别往下做
7. **装花店技能包** `codex-skills-collection`（11 个技能）
8. **跑一篇真笔记**：客户素材 → 出文案 → 客户点头 → 填进后台 → **客户自己点发布**
9. **录屏 + 留本文件**（客户桌面放一份）

## 三、报错对照表

| 屏幕上出现 | 真实原因 | 自己怎么修 |
|---|---|---|
| `Extension 未连接，请确认浏览器已安装并启用 XHS Bridge 扩展` | 扩展被关 / Chrome 没开 | `chrome://extensions` 确认开启 → 重试 |
| `Cannot access contents of url ... must request permission` | 页面被跳到未授权域名（rednote.com） | 关掉梯子「全局模式」 |
| `页面加载超时` | 页面没加载出内容 | **先手动打开同一地址，能看见内容再重试** |
| 端口 9333 被占用 | 同时开了两个任务 | 关掉多余窗口，只留一个 |
| 文案没写进后台 | 小红书改版，页面结构变了 | 找交付方修 |
