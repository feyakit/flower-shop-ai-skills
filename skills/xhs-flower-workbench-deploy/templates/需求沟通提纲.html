开场先说边界，再谈价格

“我能帮你做的，是让你每天不用自己想文案 —— 素材交给我，出来的东西你点一下就能发。
但有三样我不做，我先说清楚，免得后面你觉得我不给力：不承诺涨粉、不要你账号密码、不自动发布。”

一我能交付的

✅ 确定能做

  • 小红书文案：标题、正文、话题、封面字
  • 素材配图：裁切、加字、批量出图
  • 文案自动填进创作服务平台后台
  • 客服话术：发我聊天记录，出需求判断和回复建议
  • 每日复盘、经验库存进知识库
  • 每周数据报告（手工填表 → 我给你分析）

❌ 做不到，别答应

  • 自动发布、自动回私信、自动回微信
  • 无人值守运营
  • 承诺涨粉、曝光、成交
  • 代你操作账号（密码不给任何人）

理由一句话：平台会风控，账号受限的代价不是我赔得起的。

二必须问到的 8 个问题

  1. 小红书现在多少粉？一周发几条？自然流量为主还是投聚光？　→
  2. 聚光开户了吗？一个月大概投多少钱？　→
  3. 美团是外卖还是团购/点评？有开店宝账号吗？　→
  4. 小程序是谁做的？有后台账号吗？有源码吗？　→
  5. 电脑是 Windows 还是 Mac？哪年买的？　→
  6. 现在每天花多少时间写文案、回消息？　→ （这是报价的锚，必须问到具体小时数）
  7. 素材谁拍？每天有没有实拍图？　→ （项目死在这一题上的最多）
  8. 你最想要的是：涨粉 / 到店 / 还是“我不用自己想文案了”？　→

第 8 题如果是第三个答案 → 这单最好交付，当天就能感知价值。如果她要的是涨粉 → 先把预期降下来，再谈钱。

三美团和小程序：怎么答

问到的能做什么你要说的话
美团 评价回复文案、差评挽回、团购标题和详情、导出订单和评价 CSV 做分析。
不碰上下架、核销、自动回评。		 “评价和商品文案我能帮你写，数据你导出给我我帮你分析。但订单和核销我不动，那出错是赔钱的。”
小程序
（有赞/微盟/小商店）		 商品文案、活动页文案、图片。 “能帮你写里面的内容和活动，但后台操作要看具体是哪个平台。”
小程序
（有源码要改）		 这是开发项目，跟这单不是一回事。 “这个要单独做，我得看到代码才能报价，跟今天的部署是两笔。”

美团和小程序单独算，不要打包进 1000。多一条线就多一个失败点，而售后还是 7 天。

四报价

¥1000　=　小红书这一条线：远程部署一次（约 2 小时）+ 跑通一篇真笔记 + 操作录屏 + 7 天答疑

加价项

  • 上门（不走远程）　+500
  • 美团/聚光专项　+500
  • 月度陪跑　800–1500 / 月
  • 7 天后答疑　300 / 小时
  • 小红书改版修复　300–500 / 次

她要准备

  • ChatGPT Plus（约 145/月，需外币卡或代充）
  • 稳定梯子（小红书必须走直连，不能全局代理）
  • 每天 3 张以上的实拍素材
  • 电脑能正常打开小红书后台

五结束语 + 下一步

“那我先按小红书这条线给你部署，做完你发一篇试试。觉得有用，我们再谈美团和聚光那部分。
定金一半，跑通再付另一半。你把向日葵装上，我连上给你做，你今天就能发第一条。”

现场如果她同意：立刻约时间 → 让她今晚就把素材拍好 → 明天开工前做 5 分钟预检（让她自己打开 creator.xiaohongshu.com，你看屏幕出不出内容）。
