# Flower Shop Xiaohongshu Body And Topics

Use this reference when writing正文、话题、标签, or student-ready post copy for flower-shop Xiaohongshu notes.

## Effective Note Structure

Produce a note that is easy to copy into Xiaohongshu:

```text
{标题}

-
{情绪开场}
{2-4 lines that make the reader imagine receiving or sending the bouquet}
-
{花束描述}
{flower materials, colors, wrapping, size, texture, and style}
-
{人群 + 场景}
适合送{recipient list}
{scene list with separators}
{one conversion sentence}
-
📍{城市}花店
🚗{城市}同城可配送
💌可搭配手写贺卡，支持按预算、色系和送花对象定制
-
{topics}
```

Keep the body concise, local, and concrete. Avoid long generic praise. Prefer short lines and a few useful emoji.

## Body Requirements

- Start with emotion, not product specs.
- Describe bouquet details: main flowers, accent flowers, color palette, wrapping, ribbon, card, volume, and style.
- Connect details to a buyer reason: not easy to get wrong, photogenic, high ritual value, not awkward for boys, warm for best friends, etc.
- Name recipient and scene clearly.
- Include city/store information, delivery, appointment/customization, handwritten card, and bag only when appropriate.
- Do not invent prices. If the user provides a price, include it plainly.
- Include search keywords naturally in正文 and tags.
- Avoid direct AI-like template wording; vary openings and verbs by image.

## Recipient And Scene Vocabulary

Recipients:

- 送女朋友、送男朋友、送闺蜜、送老婆、送妈妈、送朋友、送同学、送老师、送领导、送妹妹、送姐姐、暧昧对象、喜欢的人

Scenes:

- 生日惊喜、纪念日花礼、约会见面、下班见面、异地见面、毕业花束、毕业合影、成人礼、表白花束、求婚花束、开业花礼、探店见面、日常哄开心、谢师花束

Emotional words:

- 被爱感、心动、暖哭、开心很久、温柔、清冷、高级感、仪式感、元气感、治愈、不踩雷、不撞款、拿得出手、不尴尬

## Topic Strategy

Use 8-10 topics. Put the most important 3-4 first.

Recommended order:

1. 地域人群 / local search: `#{城市}花店`, `#{城市}买花`, `#{城市}订花`
2. 核心人群: `#送女友花束`, `#送男友花束`, `#送闺蜜花束`, `#送妈妈花束`
3. 场景: `#生日花束`, `#纪念日花礼`, `#毕业花束`, `#约会花束`
4. 产品/风格: `#粉色花束`, `#蓝色花束`, `#黄玫瑰`, `#一岁一花`, `#小众花束`, `#高级感花束`
5. 转化补充: `#{城市}同城鲜花配送`, `#同城订花`
